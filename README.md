# idea-vault-web

짧은 아이디어를 적으면 태그와 연결이 붙고, 그래프로 살피고, 쌓인 노트를 근거로 질문할 수 있는 개인용 웹앱이다.

**현재 상태:** [W0 품질 시험](docs/w0.md) 스크립트를 만들었다. 실제 노트로 시험해 모델을 정하는 일이 남았다. 앱 화면은 아직 없다.

| 문서 | 내용 |

| [설계](docs/design.md) | 목표, 구조, 데이터, 흐름, 보안, 만드는 순서 |
| [결정 사항](docs/decisions.md) | 확정된 결정 |
| [W0 품질 시험](docs/w0.md) | 시험 스크립트 사용법 |
| [CLAUDE.md](CLAUDE.md) | 개발할 때 지킬 것 |

이 저장소는 공개된다. 화면 코드와 설계 문서만 두며, 노트는 별도의 비공개 저장소에 보관한다.
