# idea-vault-web

짧은 아이디어를 적으면 태그와 연결이 붙고, 그래프로 살피고, 쌓인 노트를 근거로 질문할 수 있는 개인용 웹앱이다.

**현재 상태:** [W0 품질 시험](docs/w0.md)을 마쳤다. [W1 적기와 보관](docs/w1.md)을 만드는 중이며 앱에는 아직 설정 화면만 있다.

| 문서 | 내용 |
|---|---|
| [설계](docs/design.md) | 목표, 구조, 데이터, 흐름, 보안, 만드는 순서 |
| [결정 사항](docs/decisions.md) | 확정된 결정 |
| [W0 품질 시험](docs/w0.md) | 시험 스크립트 사용법 |
| [W1 작업](docs/w1.md) | 적기와 보관 단계의 작업 목록 |
| [CLAUDE.md](CLAUDE.md) | 개발할 때 지킬 것 |

## 실행

Node 24 이상에서 `npm install` 후 사용한다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버. 보안 정책(CSP)은 적용되지 않는다 |
| `npm run build` | 타입 검사와 배포용 빌드(`dist/`) |
| `npm run preview` | 빌드한 결과 확인 |
| `npm test` | 테스트 |

## 저장소

이 저장소는 공개된다. 화면 코드와 설계 문서만 두며, 노트는 별도의 비공개 저장소에 보관한다.
