# 결정 사항

| # | 결정 사항 | 확정 |
|---|---|---|
| 1 | 구조 (2026-11-26) | GitHub Pages 정적 웹앱, 노트는 비공개 GitHub 저장소, 브라우저에서 API 직접 호출. 서버를 두지 않는다 |
| 2 | 모델 제공자 (2026-11-26) | OpenAI (태그·연결, 임베딩, 질문) |
| 3 | 노트 (2026-11-26) | 한 줄이 완성된 노트. 자동 태그, 이유가 있는 연결, 직접 잇기, 그래프. 비전은 질문할 때만 받는다 |
| 4 | 벡터 (2026-11-26) | 별도 벡터 DB 없이 브라우저(IndexedDB)에 두고 검색한다 |
| 5 | 키 보관 (2026-11-26) | 기기마다 한 번 입력하거나 `.env`를 불러온다. 별도 암호는 두지 않는다 |
| 6 | 저장소 (2026-11-26) | 새 이력으로 시작한다. 이 저장소는 공개 |
| 7 | 연결 기준 (2026-11-26) | 같은 기술·장르·소재라는 것만으로는 잇지 않고 태그로 묶는다 |
| 8 | 태그·연결과 질문 모델 (2026-11-26) | `gpt-6-luna`. `gpt-6.1-terra`는 비용 때문에 쓰지 않는다 |
| 9 | W0 종료 (2026-11-26) | 시험을 마치고 W1로 넘어간다. 연결 품질은 W2에서, 검색 품질은 W4에서 다시 확인한다 |

미해결 항목은 [설계](design.md#10-미해결)에 있다.
